# closets/ — Distilled Context

Tight, high-signal summaries of closed workstreams: what was decided,
what remains open, where the details live. Write one when a project,
review, or War Room concludes so the next session onboards in seconds.

Format per summary file (`<topic>-summary.md`):
- **Context:** one paragraph — what this was about.
- **Decisions:** bullet list with dates.
- **Open items:** what's unresolved and who owns it.
- **Pointers:** links to the room halls and drawers with full detail.
